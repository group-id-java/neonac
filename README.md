# 🟢 NeonAC

**A Minecraft anti-cheat for version 1.21.4.**

NeonAC aims to detect cheats, analyze suspicious player behavior, and help Minecraft server owners maintain fair gameplay.

## ✨ Features

- ⚔️ Combat checks
- 🎯 KillAura, AimAssist and Reach detection
- 🏃 Movement checks
- 🚀 Fly, Speed and NoFall detection
- 📊 Violation tracking
- 🔔 Staff alerts
- ⚙️ Configurable checks
- ⚡ Performance-focused design

## 🖥️ Compatibility

- Minecraft Java Edition 1.21.4
- Java 21
- Paper / Leaf

## 🚧 Development Status

NeonAC is currently under development. Features and detection methods may change as development continues.

## 📦 Installation

Installation instructions will be added when a stable build is available.

## ⚠️ Disclaimer

No anti-cheat can guarantee perfect detection. False positives and bypasses are possible. Always test your configuration before enabling automatic punishments.
